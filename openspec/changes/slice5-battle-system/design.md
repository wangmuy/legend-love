## Context

当前有 3 个游戏状态：GAME_START(0), GAME_MMAP(2), GAME_SMAP(4)。需要新增 GAME_WMAP(3) 用于战斗。
战斗基于 1D 线性距离模型，与 Love2D 原版的 war.sta 数据兼容。

## Decisions

### GAME_WMAP 状态

```lua
JY.Status = 3  -- GAME_WMAP
```

### 运行时战斗状态

```lua
JY.War = {
    enemies = {},        -- 敌方队伍 [{personId, hp, mp, x}]
    teammates = {},      -- 我方队伍 [{personId, hp, mp, x}]
    turn = 0,            -- 0=我方 1=敌方
    round = 1,           -- 回合数
    distance = 5,        -- 敌我距离
    warId = 0,           -- war.sta 中的战斗 ID
}
```

### 伤害计算公式

```
物理伤害 = 攻击力 - 防御力/2 + 随机(0~20)
武功伤害 = 武功威力 + 攻击力/3 - 防御力/3 + 随机(0~10)
```

### 菜单驱动交互（与 SMAP 一致）

```
WMAP 交互流:
  look → 战场态势 + 行动菜单（编号列表）
  choose N → 选择行动 → 子菜单 / 执行

行动菜单:
  1. 攻击        ← 普通攻击（自动选择最近敌人）
  2. 武功        ← 列出可用武功 → 子菜单选择
  3. 物品        ← 列出可用物品 → 子菜单选择
  4. 防御        ← 本回合防御，减伤
  5. 移动        ← 走近/远离 → 子菜单选择步数
  6. 查看状态    ← 查看指定角色状态

三级菜单流程：
  选队友 → 选行动 → 选目标 → 执行
  (单人战斗自动跳过"选队友")
  (唯一目标自动跳过"选目标")

选队友：我方队伍中未行动的角色列表，choose N 选择。
选目标：行动范围内的敌方列表（攻击/武功）或友方列表（物品/医疗）。
  choose N 选择目标，行动范围不足的目标标记 ❌ 但可选（武功不消耗但提示无效）。
```
