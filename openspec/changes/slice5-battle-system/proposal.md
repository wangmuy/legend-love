## 为什么

Slice 4 实现了场景交互（对话/物品/场景状态），但战斗系统还是空白。游戏的核心冲突——战斗，无法进行。玩家遇到战斗事件时没有对应的交互界面。

## What Changes

实现 1D 线性距离回合制战斗系统 [GAME_WMAP]，与 Love2D 原版的战斗逻辑一致，但交互方式改为文本命令。

### 战斗流程

```
遇敌 → 进入 WMAP → look 查看战场 → move/attack/wugong → 敌回合 → ... → 胜利/失败
```

### 1D 距离模型

```
位置 0          位置 5              位置 10
  │              │                  │
  ├─ 我方 ───────┼──── 敌方 ────────┤
  │  胡斐        │   阎基            │
  └──────────────┴─────────────────┘
        距离: 5 步
```

## Scope Boundaries

### In Scope
- GAME_WMAP 状态注册和命令
- 1D 线性距离系统（位置/移动/攻击范围）
- 回合交替系统
- AI 决策（敌方行动）
- 武功使用（含范围检查）
- 战斗物品使用
- war.sta 数据加载
- 脚本触发战斗（oldevent 调用 initWar）
- 战斗胜利/失败处理（含经验/金钱奖励）

### Out of Scope
- 多人战斗阵型
- 武功动画效果
- 战斗场景贴图
