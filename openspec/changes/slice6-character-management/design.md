## Context

Slice 4、5 的 SMAP/WMAP 交互已统一为菜单驱动（`look` → `choose N` → 子菜单）。Slice 6 将角色管理也纳入同一范式，避免引入新的直接命令。

## Decisions

### 菜单入口：`look` 输出扩展

MMAP/SMAP 的 `look` 在现有输出末尾追加角色管理菜单：

```
当前位置: ...
附近场景: ...
────────────────────────────────────────
1. 查看角色状态
2. 背包管理
3. 队伍管理
4. 存档/读档
输入 choose <编号> 选择操作
```

### 状态查看

```
> choose 1
徐小侠  Lv.1
生命: 50/50  内力: 35/35  体力: 100/100
攻击: 29  防御: 26  轻功: 25  资质: 76
武功: 野球拳 (Lv.1)
装备: 无
────────────────────────────────────────
1. 查看队员      ← 选择查看其他队员
0. 返回上级菜单
```

### 背包管理

```
> choose 2
背包 (3/30):
1. 药材 x5        ← 使用/查看
2. 金创药 x3      ← 使用（战斗中/非战斗）
3. 唐诗选辑 x1    ← 查看
────────────────────────────────────────
1. 使用物品       ← 选物品 → 选目标
2. 装备物品       ← 选物品 → 装备
3. 查看物品说明
0. 返回上级菜单
```

### 存档/读档

```
> choose 4
────────────────────────────────────────
1. 存档
2. 读档
3. 查看存档列表
0. 返回上级菜单
```

存档使用 IndexedDB，与现有 `state_manager.lua` 兼容。槽位 0 = 自动存档（场景切换/休息时），槽位 1-3 = 手动存档。

## Review Checklist

1. `look` 在 MMAP/SMAP 显示角色管理菜单
2. 角色状态查看显示属性/武功/装备
3. 背包管理可查看/使用/装备物品
4. 存档/读档通过 IndexedDB 持久化
5. 全部通过 `choose N` 菜单驱动，无新直接命令

## Negative Constraints

- 不引入新的直接命令（全走 `choose N` 菜单）
- 不修改现有 `look`/`list`/`leave` 等命令
- 不创建图形界面
- 存档格式与现有 `state_manager.lua` 兼容
