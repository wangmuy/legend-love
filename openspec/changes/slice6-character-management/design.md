## Context

Slice 4、5 的 SMAP/WMAP 交互已统一为菜单驱动（`look` → `choose N` → 子菜单）。Slice 6 将角色管理也纳入同一范式。与原版游戏一致：角色管理入口不是 `look` 的自带选项，而是通过 **ESC 主选单**（`menu` 命令）访问。

**原版游戏**按 ESC 打开主选单：系统/物品/武功/状态/存挡/读挡。Web MUD 使用 `menu` 命令作为文字替代。

## Decisions

### 入口：`menu` 命令（替代原版 ESC 键）

MMAP/SMAP 状态下输入 `menu` 打开主选单：

```
> menu
─── 主选单 ───
1. 状态
2. 物品
3. 武功
4. 系统（存档/读档）
0. 返回
输入 choose <编号> 选择操作
```

`look` 末尾仅提示 `"输入 menu 打开主选单"`，不自带菜单选项。与原版保持一致：`look` 只显示场景/地图信息，主选单由 ESC/menu 触发。

### 存档/读档

```
> menu → choose 4
─── 存档管理 ───
1. 存到槽位1
2. 存到槽位2
3. 存到槽位3
4. 读取槽位1
5. 读取槽位2
6. 读取槽位3
0. 返回
```

存档使用 IndexedDB。槽位 0 = 自动存档（场景切换时），槽位 1-3 = 手动存档。

## Review Checklist

1. `menu` 命令在 MMAP/SMAP 显示主选单
2. 角色状态查看显示属性/武功/装备
3. 背包管理可查看/使用/装备物品
4. 队伍管理可查看队员/医疗/解毒
5. 存档/读档通过 IndexedDB 持久化
6. 全部通过 `choose N` 菜单驱动，无新直接命令
7. 自动存档在场景切换时触发

## Negative Constraints

- 不引入新的直接命令（全走 `choose N` 菜单）
- 不修改现有 `look`/`list`/`leave` 等命令语义
- 不创建图形界面
- 存档格式与现有 `state_manager.lua` 兼容
