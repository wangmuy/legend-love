## 为什么

Slice 4-5 实现了场景交互和战斗系统，但玩家缺少角色管理功能：无法查看角色状态、管理背包、存档读档。当前 `instruct_52`（看品德）和 `instruct_53`（看声望）通过文本输出，但没有统一的菜单入口。存档系统只存在于 IndexedDB 基础层，没有用户交互界面。

## What Changes

实现菜单驱动的角色管理系统，在 MMAP/SMAP 状态通过 `look` → `choose N` 进入角色管理子菜单。

### 交互流程

```
MMAP/SMAP:
  > look
  当前位置: ...
  （附加菜单）
    1. 查看角色状态
    2. 背包管理
    3. 队伍管理
    4. 存档/读档

  → choose 1 → 角色状态（属性/武功/装备）
  → choose 2 → 背包（物品列表/使用/装备）
  → choose 3 → 队伍（队员列表/离队/医疗）
  → choose 4 → 存档/读档（IndexedDB）
```

## Scope Boundaries

### In Scope
- 角色状态查看（属性/武功/装备）
- 背包管理（查看物品/使用/装备/卸下）
- 队伍管理（查看队员/离队/医疗/解毒）
- 存档/读档（IndexedDB 持久化）
- 全部通过 `look` + `choose N` 菜单驱动

### Out of Scope
- 图形界面
- 多人游戏
- 物品交易（NPC 商店）
- 武功修炼动画
