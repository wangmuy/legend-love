## Context

WMAP 状态的战斗命令全部通过菜单驱动（look + choose），无独立命令。
与 SMAP 一致，`choose N` 路由到队友/行动/目标三级选择。

## Decisions

```
look → 战场态势 + 可选队友
choose N → 选队友 → 行动菜单 → 选目标 → 执行
```

行动菜单：攻击/武功/物品/防御/移动/查看
