# 14 天书收集攻略 — 规格说明

## [REQ-WT-003-01] 天书事件脚本解锁

| 字段 | 值 |
|------|-----|
| 名称 | 天书事件脚本解锁 |
| 优先级 | P0 |
| 验证方式 | Lua 语法检查 + e2e 测试 |

**Given** 天书场景的 oldevent 脚本被注释
**When** 取消 `--function` 注释
**Then** 脚本可被 Lua 加载执行，无语法错误

**Given** 玩家在天书场景中
**When** 选择对应 NPC → 对话
**Then** 事件脚本执行，终端输出天书相关对话文本

## [REQ-WT-003-02] 天书获取 e2e 测试

| 字段 | 值 |
|------|-----|
| 名称 | 天书获取 e2e 测试 |
| 优先级 | P1 |
| 验证方式 | 自动化 e2e 测试 |

**Given** 游戏已推进到对应天书场景
**When** 玩家与 NPC 对话触发事件
**Then** 事件执行完成，无 gameLoop error

**Given** 天书事件已执行
**When** oldevent 脚本包含 `instruct_2`（给物品）
**Then** 玩家获得对应天书物品

## [REQ-WT-003-03] 圣堂放置天书验证

| 字段 | 值 |
|------|-----|
| 名称 | 圣堂放置天书 |
| 优先级 | P1 |
| 验证方式 | 自动化 e2e 测试 |

**Given** 玩家在圣堂场景中
**When** 输入 `look`
**Then** 终端显示 14 个"放置天书"事件选项

**Given** 玩家选择了一个书架事件
**When** 事件触发
**Then** 显示"是否使用物品"对话框，事件正常返回，无 gameLoop error
