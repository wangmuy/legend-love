## 1. MMAP 命令

- [x] 1.1 `list`：从 entrances.json 列出场景（编号 + 名称 + 坐标）
- [x] 1.2 `go <场景名>`：精确匹配场景名，更新 JY 坐标，切换到 GAME_SMAP
- [x] 1.3 `go <场景名>`：模糊匹配场景名（子串匹配）
- [x] 1.4 `go <场景名>`：找不到场景时给出提示
- [x] 1.5 `look`：显示当前位置、附近场景列表
- [x] 1.6 `where`：显示坐标和方位描述

## 2. SMAP 命令

- [x] 2.1 `look`：显示场景名称、描述、NPC 列表、出口
- [x] 2.2 `exits`：列出出口方向 + 目标场景名
- [x] 2.3 `go <编号>`：匹配出口编号，切换场景或回到大地图
- [x] 2.4 `go <方向>`：无此出口时给出提示

## 3. 场景描述模板

- [x] 3.1 基于场景类型/名称关键词匹配模板（客栈/民宅/山洞/门派/商店/树林等）
- [x] 3.2 默认场景描述：无匹配时使用通用模板

## 4. 命令注册

- [x] 4.1 MMAP 命令注册到 CommandEngine
- [x] 4.2 SMAP 命令注册到 CommandEngine
- [x] 4.3 在 framework 初始化完成后自动注册
