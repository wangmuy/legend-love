## 数据来源

运行时数据直接读取 `data/ranger.grp` 二进制（不通过 jyconst.lua）。

游戏中 `jyconst.lua` 定义了 CC.Char_S、CC.Thing_S、CC.Skill_S 的结构描述（字段偏移/类型/长度），提取脚本复用这些常量定义来解析 ranger.grp 中对应数据段。

人物段：ranger.grp idx[1] → 187 条 × 140 字节
物品段：ranger.grp idx[2] → 199 条 × 260 字节
武功段：ranger.grp idx[4] → 100 条 × 150 字节

不使用通过 `dofile("jyconst.lua")` 再读取 JY.Person 表的方式，因为 ranger.grp 的值是游戏初始化后的"当前状态"，与再运行一次初始化的结果一致，但更直接。

## 输出格式

### chars.json

```json
{
  "version": "1.0",
  "total": 187,
  "chars": [
    {
      "代号": 0, "姓名": "徐小俠",
      "等级": 1, "生命": 50, "内力": 30,
      "攻击力": 30, "防御力": 30, "轻功": 30,
      "品德": 80, "声望": 0, "资质": 80,
      "武功1": 1, "武功等级1": 1,
      "武功2": 0, "武功等级2": 0,
      "携带物品1": 0, "携带物品数量1": 0,
      ...
    }
  ]
}
```

所有字段名直接使用 CC.Char_S 定义的中文名。

### items.json

```json
{
  "version": "1.0",
  "total": 199,
  "items": [
    {
      "代号": 0, "名称": "药材",
      "类型": 3, "装备类型": 0,
      "加生命": 20, "加内力": 0,
      "需内力": 0, "需攻击力": 0,
      ...
    }
  ]
}
```

物品 type: 0=剧情 1=武器 2=防具 3=药品 4=暗器 5=秘籍 6=装备材料

### skills.json

```json
{
  "version": "1.0",
  "total": 100,
  "skills": [
    {
      "代号": 1, "名称": "野球拳",
      "武功类型": 0, "攻击力1": 100,
      "消耗内力点数": 0, "攻击范围": 0,
      "移动范围1": 1, "杀伤范围1": 1,
      ...
    }
  ]
}
```

武功 type: 0=拳掌 1=剑法 2=刀法 3=特殊 4=内功
