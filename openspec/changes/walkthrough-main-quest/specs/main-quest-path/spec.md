# 攻略主线 e2e 测试 — 规格说明

## [REQ-WT-002-01] Phase 1 快速通关

| 字段 | 值 |
|------|-----|
| 名称 | 快速通关主线测试 |
| 优先级 | P0 |
| 验证方式 | 自动化 e2e 测试 |

**Given** 游戏页面已加载
**When** 选择新游戏 → 确认属性 → 与软体娃娃对话
**Then** 终端输出包含"新游戏开始"和"软体娃娃"的对话文本

**Given** 在主角的家场景
**When** 输入 leave
**Then** 进入大地图，终端显示"当前位置"和坐标

**Given** 在大地图
**When** list → choose N（河洛客栈）→ 进入
**Then** 终端显示"河洛客棧"和客栈描述

**Given** 在河洛客栈
**When** choose N（掌柜）→ 对话
**Then** 终端显示掌柜对话文本，包含"住宿"相关文字

**Given** 游戏已推进到南贤居
**When** 与南贤对话
**Then** 对话可执行，无 gameLoop error

## [REQ-WT-002-02] Phase 2 完整攻略

| 字段 | 值 |
|------|-----|
| 名称 | 完整主线攻略测试 |
| 优先级 | P1 |
| 验证方式 | 自动化 e2e 测试 |

**Given** 游戏已从开局推进到中期
**When** 完成至少 1 本天书的收集流程
**Then** 天书收集过程无 gameLoop error

**Given** 游戏已推进到后期
**When** 触发战斗
**Then** 战斗可完成，无 gameLoop error

**Given** 已满足通关条件
**When** 完成通关必需的步骤序列
**Then** 游戏成功通关，无 gameLoop error

## [REQ-WT-002-03] 步骤独立可重跑

| 字段 | 值 |
|------|-----|
| 名称 | 测试步骤独立性 |
| 优先级 | P1 |
| 验证方式 | 自动化验证 |

**Given** 攻略测试已运行过一轮，所有存档已生成
**When** 单独运行第 N 步测试（从对应存档加载）
**Then** 测试通过，输出与全量运行时一致
