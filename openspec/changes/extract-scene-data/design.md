## 数据来源

场景元数据从 `data/ranger.grp` 的 Scene_S 段读取（62 字节/条 × 84 条场景）。

Scene_S 是场景元数据的唯一存储位置——包含名称、出口坐标、跳转目标、入口坐标、进入条件等。虽然在 Love2D 中 `allsin.grp` 存储场景贴图数据（64×64×6 层 int16），`mmap.grp` 和 `earth.002` 等存储大地图瓦片数据，但场景的结构化元数据只存在于 ranger.grp 的 Scene_S 段。

## 提取方法

1. 读取 data/ranger.idx 获取场景段偏移
2. 按 CC.Scene_S 结构读取每个场景的 62 字节二进制数据
3. 解析 21 个字段（中文键名）：名称、入口坐标、出口坐标、跳转目标、NPC/物品等
4. 输出场景数组

## 输出格式

```json
{
  "version": "1.0",
  "extracted": "2026-06-07",
  "total": 84,
  "scenes": [
    {
      "代号": 70,
      "名称": "河洛客栈",
      "外景入口X1": 357, "外景入口Y1": 235,
      "入口X": 13, "入口Y": 10,
      "出口X1": 15, "出口Y1": 19,
      "跳转口X1": 1, "跳转口Y1": 1,
      "进入条件": 0,
      "NPC1": 137, "NPCX1": 13, "NPCY1": 8,
      "物品1": 47, "物品X1": 4, "物品Y1": 6
    }
  ]
}
```

注：场景不包含 `type` 字段（场景类型推断在运行时由命令模块处理，不在数据层）；不包含 `idStr`（使用中文名称作为标识）。
