## allsin 二进制格式

```
allsin.idx:
  每条 4 字节偏移量
  记录数 = 文件大小 / 4
  每条偏移量指向 allsin.grp 中一条场景记录

allsin.grp:
  每条场景记录包含:
  - 场景名称 (不定长字符串)
  - 场景宽度/高度 (short)
  - 场景类型标记
  - 关联的 s* 文件索引
```

## s* 文件

场景地图文件。每个场景对应一个 s 文件和 t 文件（`s%d.grp` / `t%d.grp`）。
包含场景的地面层、建筑层、事件层数据。

## d* 文件

场景事件定义文件。`d%d.grp` 包含场景事件触发数据。

## NPC 和物品坐标

NPC 和物品位置存储在 allsin 数据中，包含人物编号/物品编号和场景内坐标。

## 场景类型推断

从场景名关键词推断：
- 包含"客栈"/"店"/"楼" → "inn"
- 包含"洞"/"穴"/"墓" → "cave"
- 包含"寺"/"庙"/"庵" → "temple"
- 包含"铺"/"坊"/"市" → "shop"
- 包含"居"/"宅"/"庄" → "house"
- 其他 → "outdoor"
