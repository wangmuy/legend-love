## ADDED Requirements

### Requirement: 场景结构提取

系统 SHALL 从 `data/ranger.grp` 的场景段（Scene_S 结构）中提取场景元数据。

场景元数据包括：名称、出口坐标、跳转目标、入口坐标、进入条件、出门/进门音乐等。
不来自 `allsin.grp`（该文件只存储场景贴图数据 64×64×6 层 int16）。

#### Scenario: 提取场景列表
- **GIVEN** ranger.grp 存在于 `data/` 目录
- **WHEN** 运行提取脚本
- **THEN** 读取所有场景的 Scene_S 基础信息（代号、名称）

#### Scenario: 提取场景出口
- **WHEN** 处理每个场景时
- **THEN** 从 Scene_S 的出口字段（出口X1-3、出口Y1-3、跳转口X1-2、跳转口Y1-2）解析出口位置和目标场景 ID

#### Scenario: 提取入口坐标
- **WHEN** 处理每个场景时
- **THEN** 从 Scene_S 的外景入口字段（外景入口X1/Y1、外景入口X2/Y2）解析入口坐标

#### Scenario: 场景 JSON 输出
- **WHEN** 读取 scenes.json
- **THEN** 每条场景记录使用中文键名包含：
  - `代号`: 场景编号
  - `名称`: 场景名称
  - `出口X1-3` / `出口Y1-3`: 出口坐标
  - `跳转口X1-2` / `跳转口Y1-2`: 跳转目标
  - `外景入口X1/Y1` / `外景入口X2/Y2`: 大地图入口坐标
  - `入口X/Y`: 场景内进入点
  - `进入条件`: 入口条件
  - `NPC1-3` / `NPCX1-3` / `NPCY1-3`: NPC 坐标
  - `物品1-3` / `物品X1-3` / `物品Y1-3`: 物品坐标
