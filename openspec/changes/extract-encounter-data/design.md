## 战斗地图数据

战斗地图数据从 `data/fight*.grp` 读取，包含每个战斗场景的瓦片布局。
文字版不需要瓦片数据，只提取战斗地图的编号、名称、可通行格数。

## 遇敌配置

遇敌配置从 `data/war.sta` 读取（146 条 × 17 字节 = 固定二进制格式）：

每条含：
- 场景/区域 ID
- 敌人组合（最多 4 种敌人 × 等级范围）
- 遇敌概率
- 战斗地图 ID

## 输出格式

```json
{
  "version": "1.0",
  "extracted": "2026-06-07",
  "warMaps": [
    { "id": 1, "name": "悦来客栈外", "count": 0, "walkable": 312 }
  ],
  "encounters": [
    {
      "sceneId": 1, "prob": 30,
      "enemy1": 50, "enemy1Level": 5,
      "enemy1Count": 2, "enemy2": -1,
      ...
    }
  ]
}
```

遇敌配置使用中文键名（如 `场景代号`、`遇敌概率`、`敌人1` 等）。

## 用途

在 Slice 5（战斗系统）中，玩家进入场景或在大地图移动时，
根据 encounters 配置决定是否遇敌和遇到什么敌人。
