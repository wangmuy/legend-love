# 金庸群侠传 Web MUD - 完整通关操作手册

本文档记录从开局到通关的完整用户操作流程，对应 `walkthrough-p1~p10` 自动化测试。
每个步骤均为纯用户命令（`leave`/`list`/`look`/`choose <N>`），可在终端中手动验证。

---

## 操作说明

- `choose N` — 选择菜单项/交互对象/对话选项
- `list` — 在大地图列出可去场景（按名称排序，顺序稳定）
- `leave` — 离开当前场景返回大地图
- `look` — 查看当前位置或战场态势
- `menu` — 打开主选单（医疗/解毒/状态/物品/队伍/存档/踢人）
- `help` — 显示帮助

### gotoScene 自动导航流程

```
choose 0 × 3   ← 关闭可能残留的对话框/菜单
leave           ← 回到大地图
list            ← 列出可去场景（按名称排序）
choose <idx>    ← 按名称找到场景索引，导航
```

### 验证清单（手动操作时可对照）

- 南贤居 → 显示"一间普通的民居"（非客栈）
- 田伯光居 → 显示"一间普通的民居"（非客栈）
- 田伯光加入 → 选"是"后走加入剧情（不走战斗路线）
- 闫基战斗 → 战斗胜利后显示获奖信息
- 各场景描述应与场景类型匹配（民居/山洞/客栈等）

### 存档跳转结构

测试使用存档跳转模式，每个步骤独立可重跑：
- 每个 `walkthrough-pN.spec.js` 从 JSON 文件恢复存档缓存
- 每步执行：`loadTestState(slot)` → 操作 → `saveTestState(slot)`
- 跨 spec 文件通过 `bridge-pN.json` 传递存档缓存
